# PMO · Портфель ИТ-проектов

React-приложение для руководителя проектов Дирекции ИТ: ведение портфеля из 3–5 проектов
полного цикла — от бизнес-запроса до запуска и сопровождения.

## Запуск

```bash
npm install
npm run dev
```

## Модули и требования вакансии

| Вкладка | Что закрывает |
|---|---|
| **Портфель** | Одновременное ведение нескольких проектов, RAG-статусы (сроки / бюджет / риски), загрузка внутренних ИТ-команд и подрядчиков, открытые корректирующие действия |
| **Проект** | Жизненный цикл (Инициация → Сопровождение), контрольные точки план/прогноз/факт, бюджет план/факт/прогноз (EAC), автоматическое выявление отклонений, план корректирующих действий, участники (заказчик, БА, архитектор, подрядчики) |
| **Инициативы** | Перевод бизнес-запроса в формализованную инициативу: цель, KPI, рамки, CAPEX/OPEX, эффект, окупаемость; чек-лист валидации; воронка до запуска проекта |
| **Статус-отчёт** | Автоматически собираемый статус проекта — копирование и печать в PDF |
| **Проектный комитет** | Пакет к комитету: сводка портфеля, вопросы на решение (доп. бюджет, перенос сроков) и защита новых инициатив |

Пороги отклонений задаются в `src/metrics.js` (`THRESHOLDS`). Данные хранятся в `localStorage`,
кнопка «Сбросить демо» возвращает демонстрационный портфель.

## Структура

```
src/
  main.jsx, App.jsx      — точка входа и навигация
  store.jsx              — состояние (useReducer + localStorage)
  data.js                — демо-портфель розничной сети
  metrics.js             — расчёт бюджета, сроков, RAG, отклонений
  components/            — Portfolio, ProjectView, Intake, StatusReport, Committee, ui
```
